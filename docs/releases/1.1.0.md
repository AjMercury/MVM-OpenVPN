# MVM 1.1.0

- Separate server and user screens for OpenVPN, WireGuard, SSTP, IKEv2 and L2TP/IPsec. Compact server forms validate inputs before previewing ordered router changes. Domain names are optional; certificate identities can use the supplied IP.
- WireGuard users receive automatically allocated addresses, downloadable configuration files and configuration QR codes. OpenVPN retains encrypted private-key configuration export. PPP services allocate addresses from their configured pools.
- Colored monitoring graphs cover resource usage, interface traffic, VPN sessions, IPsec peers, reachability and jobs, with bounded persisted history.
- Network & NAT selects existing router interfaces and VPN ranges, pools or interface networks. Exact pool ranges are converted to CIDRs. Forwarding changes require explicit selection and reviewed jobs; source and rule ownership are rechecked before application.
- Administrators can choose simple panel passwords (1–233 bytes); empty passwords remain invalid. VPN credentials and export passphrases retain their own requirements.
- Fix language switching losing service/page identifiers. Recheck OpenVPN resource ownership and WireGuard peer scope before export or user actions. Purge legacy terminal IPsec secrets and verify newly created firewall resources remain enabled.

RouterOS mutations remain experimental and disabled by default. IKEv2 provisions disabled infrastructure pending client identity enrollment; it is not a complete client enrollment flow. Automated mock-router tests do not establish interoperability with real RouterOS devices or VPN clients.

Upgrade with the existing installation's update menu or:

```bash
curl -fsSL https://raw.githubusercontent.com/AjMercury/MVM-OpenVPN/master/install.sh | sudo bash -s -- --action update
```

Back up the database and master key together before upgrading. Release archives include checksums, SBOMs and GitHub build attestations for Linux amd64 and arm64.
