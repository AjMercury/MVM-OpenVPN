# MikroTik VPN Manager 1.0.0

First stable Linux manager release, targeting the native Ubuntu 24.04 amd64 installation path. RouterOS VPN automation remains experimental and disabled by default; hardware/client interoperability and effective firewall/offboarding acceptance still require an authorized lab. Other OS/architecture targets do not imply equivalent runtime validation.

## Installation

```bash
curl -fsSL https://raw.githubusercontent.com/AjMercury/MVM-OpenVPN/master/install.sh | sudo bash
```

The installer discovers the stable release, verifies its workflow identity, tag and signed checksum manifest, then opens the credential wizard. No GitHub login is required. The official Sigstore public-good root is pinned by commit and SHA-256 independently of release assets, avoiding the TUF CDN that returns HTTP 403 on some networks. Signature checks are never skipped. Preview acceptance is requested once only; stable releases do not request preview acceptance. Missing releases are reported before installing the GitHub verifier.

Default access is local only. Follow the displayed SSH tunnel, or configure trusted TLS and review the management firewall for remote access. Existing preview data/key must be preserved and upgraded through `sudo mvm`; do not reinstall over existing state.

## Fixes

- Separate account and IP login budgets; successful login resets its counters. Trust only explicitly configured reverse proxies; the supplied Caddy deployment has a fixed trusted address.
- Expired unapplied previews release their IP/username reservations, including provably unapplied legacy expiration records. Ambiguous operations retain reservations.
- Remove PPP passwords from terminal jobs and clean historical terminal job secrets during maintenance.
- Purge expired sessions, including legacy records without embedded identifiers; log maintenance failures.
- Honor listener addresses in health checks; refuse router deletion when dependency reads fail.
- Preserve successful download delivery if the post-consumption audit write fails; require a pre-consumption audit and log failures.
- Upgrade quic-go to 0.59.1 and repair the Trivy action reference.

## Limits

MFA, automatic certificate renewal/CRL enforcement, full router/server/user editing and distributed/multi-instance operation are not included. An interrupted single-use download requires a newly issued link. Host compromise or lost master keys are outside local encryption protection. Read `docs/limitations.md` and keep verified backups.

Pre-publication [quality checks](https://github.com/AjMercury/MVM-OpenVPN/actions/runs/39173458360) and [Ubuntu 24.04 stable lifecycle](https://github.com/AjMercury/MVM-OpenVPN/actions/runs/39173296693) pass, including race tests, Go vulnerability scanning, secret scanning and both architecture container scans. The tag workflow repeats build/security/native lifecycle gates and then tests public stable installation. Final publication evidence is recorded in `docs/verification.md`.
