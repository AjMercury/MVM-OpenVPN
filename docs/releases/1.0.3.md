# MVM 1.0.3

- Native installation defaults to direct HTTP on automatically detected server IPv4 addresses; certificates are optional. HTTP credentials/session traffic are unencrypted.
- Optional Let's Encrypt domain/public IPv4 certificates through `mvm ssl`, with standalone or existing-web-server webroot validation and automatic systemd renewal. Public IPs use the short-lived profile. The official ACME client is independently pinned and verified before execution.
- Grouped, colored terminal manager displays the actual version, service state, protocol, port and URL. Failed commands return to the menu. `NO_COLOR` disables ANSI styling.
- `mvm access --http` converts an existing installation without changing its port, accounts, database or master key. Failed certificate deployment restores the previous configuration.
- HTTPS retains Secure cookies and HSTS. Explicit HTTP uses compatible session cookies while retaining CSRF and exact-origin checks. Installation progress remains visible.

Upgrade:

```bash
curl -fsSL https://raw.githubusercontent.com/AjMercury/MVM-OpenVPN/master/install.sh | sudo bash -s -- --action update
sudo mvm access --http
sudo mvm
```

Use menu 17 for optional HTTPS. The HTTPS setup guide explains public port 80, webroot and private-IP requirements. Real public CA issuance requires your own domain/public IP; mocked tests do not establish successful issuance on your network. RouterOS writes remain experimental and disabled by default.
